# Daniel Fotografia — Plano Essencial (Agência RIDA)

> Interface de alta fidelidade visual desenvolvida para o nicho de fotografia autoral e comercial.

## ⚡ Destaques do Projeto

- **Hero com Fanned Card Deck**: Efeito de leque de cards em 3D interativo com fotos de alta resolução.
- **Tipografia Cinética**: Efeito layered de contorno e preenchimento com pilar vermelho de contraste.
- **Catálogo com Spotlight**: Filtro de abas por categoria com efeito de iluminação dinâmica que acompanha o cursor.
- **Engenharia Tátil**: Feedback físico em todos os elementos clicáveis (`active:scale-[0.97]`).
- **Layout Responsivo**: Construído 100% em Flexbox e CSS Grid (Mobile-First).

## 🚀 Como Executar

Clone o repositório e abra o arquivo `index.html` no navegador:

```bash
git clone https://github.com/Davixavier2010/projeto13-fotografo.git
cd projeto13-fotografo
```
